## B12. DNS-безопасность netru.ru.net — ЗАКРЫТО 12.10.2026 (DNSSEC через Cloudflare)

Находка от внешнего консультанта (DMARC/DKIM/CAA/DNSSEC отсутствовали), верифицирована `dig`
11.10.2026. Решено через панель SpaceWeb 11.10.2026: CAA, DMARC (`p=none`), SPF (`-all`)
добавлены; DKIM отложен сознательно (нет исходящей почты с домена). SpaceWeb не поддерживает
DNSSEC для зоны (прямой ответ техподдержки 12.10.2026: «на данный момент возможность включения
DNSSEC в SpaceWeb не предусмотрена»).

**Решение DNSSEC — миграция DNS-зоны на Cloudflare (12.10.2026):**
- NS переключены: `ali.ns.cloudflare.com`, `dexter.ns.cloudflare.com` (были
  `ns1/ns2.spaceweb.ru`, `ns3/ns4.spaceweb.pro`).
- Все записи (A, SPF, DMARC, CAA) перенесены при импорте зоны, проверены `dig` после миграции.
- ⚠️ Импорт включил проксирование Cloudflare («Proxied») на A-записи по умолчанию — исправлено
  на «DNS only» (риск: edge-сертификат Cloudflare вместо нашего certbot, порт 25305 не в списке
  поддерживаемых Cloudflare портов). CAA при импорте дополнился сторонними CA — очищено до
  единственной `letsencrypt.org`.
- DNSSEC включён в Cloudflare, статус «pending» до добавления DS-записи у регистратора домена
  (Ru-Center/REG.RU). DS-запись добавлена оператором 12.10.2026, пропагация не завершена на
  момент записи — **проверить в начале следующей сессии**: `dig netru.ru.net DS`,
  `dig netru.ru.net SOA +dnssec` (ожидать RRSIG в ответе).
