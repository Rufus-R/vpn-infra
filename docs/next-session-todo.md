## 6. Правила

- Перед любым `rsync`/`scp` на Panel сверять `WorkingDirectory` юнита
  (`/etc/systemd/system/netru-bot.service`) и `DB_PATH` (`grep DB_PATH /opt/netru-bot/src/.env`):
  инциденты 09–10.10 (деплой не в тот каталог, два файла `bot.db`).
- Не использовать `git add -A` (артефакт `secrets/.gitkeep`); `git --no-pager` для diff/log; в
  многострочных вставках `ssh -n`.
- Изменения firewall на S2 — только через `ufw` (NAT в `/etc/ufw/before.rules`); не
  использовать `iptables -I/-A` и без нужды `ufw reload` (после reload проверить
  `iptables -t nat -S POSTROUTING`: по одной строке на подсеть). Бэкап S2:
  `/root/fw-backup-20261001-143917/`.
- Не трогать `/etc/x-ui/certs/server.crt` на S2 (relay 10001, pin на S_RU). Рестарт x-ui рвёт
  Xray на секунды.
- Откат `x-ui.db` на S_RU — только через `/root/restore-xui-db.sh <бэкап>`:
  `/root/x-ui.db.backup-20261001-215924` (до geo-split),
  `/root/x-ui.db.good-geosplit-20261001-231259` (рабочее). На S2:
  `/root/x-ui.db.backup-s2-20261002-002336`.
- Тег RU-доменов — `geosite:category-ru` (не `geosite:ru`); правки geo-баз сразу проверять
  `xray run -test`.
- `secrets/.gitkeep` в `git diff --stat` (22 байта → 0) при пустом `git status` — артефакт фильтра `git-crypt` (проверено 20.10.2026: `git check-attr` показывает `filter: git-crypt`); не стейджить и не коммитить.
