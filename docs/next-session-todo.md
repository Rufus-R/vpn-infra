## C. Предупреждения

- ✅ [СНЯТО 04.10.2026] Версии Xray на S_RU и S2 синхронизированы (26.9.30) после автообновления панели до v3.9.0 (03.10.2026). Регрессия Reality-хендшейка НЕ воспроизвелась: `testS2` (прямое подключение к S2) и реальные клиенты на S_RU:443 работают штатно. Прежнее предупреждение «не нажимать Update Xray» снято.
- Изменения firewall на S2 — только через `ufw` (NAT в `/etc/ufw/before.rules`). Не использовать `iptables -I/-A` и без нужды `ufw reload` (возможен дубль NAT; после reload проверить `iptables -t nat -S POSTROUTING`: по одной строке на подсеть). Бэкап S2: `/root/fw-backup-20261001-143917/` (откат: `ufw --force disable`, `iptables-restore < iptables-live-final.v4`, без персистентности).
- Не трогать `/etc/x-ui/certs/server.crt` на S2 (relay 10001, pin на S_RU). Продление IP-сертификатов рестартит x-ui (Xray на секунды).
- Откат `x-ui.db` на S_RU — только через `/root/restore-xui-db.sh <бэкап>`: `/root/x-ui.db.backup-20261001-215924` (ДО geo-split), `/root/x-ui.db.good-geosplit-20261001-231259` (рабочее). На S2 бэкап перед сменой путей панели: `/root/x-ui.db.backup-s2-20261002-002336`.
- Тег RU-доменов — `geosite:category-ru` (не `geosite:ru`); правки geo-баз сразу проверять `xray run -test`.
- Не использовать `git add -A` (артефакт `secrets/.gitkeep`).

### B10. [ПОВЫШЕННЫЙ ПРИОРИТЕТ] Встроенная страница подписки рекомендует Sing-box — несовместимый клиент
- Находка 06.10.2026 (продолжение диагностики Hiddify, см. B9 и `migration-3xui.md`, «Сессия
  06.10.2026»): нативная SPA-страница подписки x-ui v3.9.0 (вкладка «Приложения») показывает
  кнопки для Android/iOS, включая **Sing-box** — приложение на том же несовместимом с REALITY
  (Xray ≥26.9.8) ядре, что и Hiddify. Кнопка — deep-link, открывающий подписку в уже установленном
  приложении (не ведёт в сторы). Риск: пользователь с установленным Sing-box получит тот же сбой
  REALITY-аутентификации и решит, что сервис не работает.
- Список приложений зашит в скомпилированный frontend-бандл x-ui (embed.FS, сжатый — не виден
  через `strings` по бинарнику), штатных настроек панели для скрытия/редактирования списка нет
  (проверены все `sub*`-ключи в `settings`, подходящего нет).
- Единственный официальный способ изменить список — полная замена страницы подписки через
  `Sub Theme Directory` (подтверждено рабочим 06.10.2026: content negotiation по заголовку
  `Accept: text/html` отдаёт кастомный `index.html`, если он есть по указанному пути;
  `?html=1`-параметр из внешнего исследования не подтвердился — управление только через
  `Accept`, не через query-параметр).
- Вариант решения (не реализовано, требует отдельной сессии): сторонний community-шаблон
  Row-Template (github, автор frank0live, 17 дизайнов, поддержка 3X-UI/MHSanaei) — **требует
  обязательного ревью исходного кода перед установкой** (весь поток выдачи VPN-конфигов реальным
  клиентам пройдёт через чужой HTML/JS). Альтернатива — написать свой минимальный `index.html`.
- Не блокирует: текущие тестовые клиенты, запуск бота (B8 закрыт). Нужно решить до начала
  привлечения реальных платных пользователей.
