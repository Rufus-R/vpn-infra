## Критерий: платёжный дескриптор ≠ эмоциональный бренд

Хорошее название подписки должно проходить тест: «Человек, который забыл, что
он купил, за 3 секунды должен понять, за что списались деньги» — иначе риск
чарджбэков (воспринимается как мошенничество) или негативных отзывов
(«что это за хрень списывает деньги»).

| Слой | Главный критерий | Подходят метафоры? |
|---|---|---|
| **Платёжный дескриптор / чек** | Узнаваемость и нейтральность | Нет — только прямое описание |
| **Витрина / лендинг / бот** | Эмоция и привлекательность | Да — метафоры работают отлично |

## Варианты: метафоры «спокойствия»

| Вариант | Почему работает |
|---|---|
| **Штиль** | Безветренная, ровная гладь — метафора «ровного, без сбоев» соединения. Коротко, легко брендируется |
| **Гавань** | Безопасная бухта — ассоциация с защитой, бытовое слово |
| **Компас** | Про «найти свой путь» — УТП «доступ откуда угодно» без слова «обход» |
| **Маяк** | Ведёт к берегу, свет в темноте — чуть более пафосно, для премиум-позиционирования |
| **Тихая гавань** | Сильнее «Гавани» за счёт прилагательного |
| **Ровный ход** | Разговорное, бытовое — стабильность без технической коннотации |

## Варианты: тарифный словарь (привычный глазу)

| Вариант | Комментарий |
|---|---|
| **Пакет «Комфорт»** | Калька с тарифов связи/страховок — максимально привычно |
| **Тариф «Свободный»** | Несёт смысл без прямого указания на обход блокировок |
| **Пакет «Надёжный доступ»** | УТП про стабильность для работы/учёбы |
| **Тариф «Личный»** | Просто, нейтрально, расширяемо (Личный Mini / Pro) |
| **Абонемент «Своя сеть»** | В резерве — слово «сеть» может читаться двояко |

## Предложенная архитектура названий

| Контекст | Название | Почему |
|---|---|---|
| **Бренд на лендинге / в боте / в рекламе** | Штиль / Цифровой проездной | Эмоция, запоминаемость |
| **Чек, App Store, банк, пуш о списании** | Личный доступ / Пакет «Комфорт» | Узнаваемо через 2 месяца, не тревожит |
| **Название функции внутри приложения** | Сетевой щит | Риска распознавания нет — контекст внутри приложения понятен |

## Отклонённые/рискованные варианты

- **«Цифровой проездной»**, **«Цифровое спокойствие»** — сильные метафоры, но
  слабые идентификаторы: через 2 месяца пользователь не свяжет списание в
  выписке с покупкой → риск чарджбэка или негативного отзыва. Годятся только
  для бренда/лендинга, не для платёжного дескриптора.

## Топ-3 (черновой, 06.10.2026)

1. **Штиль** — эмоция + нейтральность + простота, подходит и для лендинга, и
   как короткое название в чеке.
2. **Личный доступ** — самый безопасный вариант для платёжного дескриптора.
3. **Цифровой проездной** — для бренда/лендинга, не как единственное название
   в выписке.
