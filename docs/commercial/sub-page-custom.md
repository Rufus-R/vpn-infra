## Итог

Собственный `index.html` (не сторонний Row-Template) заменяет встроенную SPA-страницу

## Механизм подключения темы (подтверждено)

- Настройка: **Settings → Subscription → Sub Theme Directory** (`subThemeDir` в `settings`).
- Файл: `index.html` в указанной директории, абсолютный путь.
- Content negotiation по заголовку `Accept`: `text/html` → кастомная тема; иначе (VPN-клиенты)
  → голый base64 конфигов (не затрагивается темой).
- ⚠️ **`subThemeDir` — настройка глобальная**, относится ко всей панели, не к конкретному
  клиенту/инбаунду. Переключение темы одномоментно меняет вид **всех** существующих ссылок
  подписки. 08.10.2026 переключено с `test-safe` (debug-шаблон, см. ниже) на `sub-shtil` —
  решение принято безопасным, так как платных клиентов на тот момент не было.

## Переменные Go-шаблона (`html/template`) — 8 шт., подтверждены живым тестом

| Переменная | Назначение |
|---|---|
| `{{ .subTitle }}` | Название подписки (заполнено: «Штиль») |
| `{{ .subSupportUrl }}` | Ссылка поддержки (не заполнено) |
| `{{ .subUrl }}` | Полная ссылка подписки (используется в кнопках приложений, fetch для статуса) |
| `{{ .subJsonUrl }}` | Ссылка JSON-формата (не заполнено) |
| `{{ .subClashUrl }}` | Ссылка Clash-формата (не заполнено) |
| `{{ .downloadByte }}` / `{{ .uploadByte }}` / `{{ .totalByte }}` | Байты (не используются в финальной версии — см. находку ниже про более полный источник) |
| `{{ range .links }}...{{ end }}` | Список `vless://...` ссылок конкретных серверов клиента |

`window.__SUB_PAGE_DATA__` (внутренний JSON встроенного React-бандла) — **не доступен** в
кастомной теме, не связан с Go-шаблоном. Подтверждено прежней сессией, актуально.

## НОВАЯ находка 08.10.2026: срок действия и трафик — через HTTP-заголовок, не через Go-переменные

Штатные Go-переменные `*Byte` не дают даты истечения вообще, а трафик не обновляется без
перерендера страницы сервером. Обходной путь — **client-side `fetch(subUrl)`** (тот же origin,
без explicit `Accept: text/html`, то есть браузерный fetch по умолчанию с `Accept: */*`):

- Подтверждено curl-тестами 08.10.2026: при `Accept: */*` (как у `fetch()`) ответ содержит
  заголовок `Subscription-Userinfo: upload=X; download=Y; total=Z; expire=T`.
- При `Accept: text/html` (режим кастомной HTML-страницы) **этот заголовок отсутствует** —
  поэтому его нельзя прочитать на этапе рендера шаблона, только последующим JS-запросом.
- Формат `expire` — **Unix-секунды** (подтверждено контролируемым тестом: `expiryTime` из API,
  мс, делённое на 1000 с усечением, точно совпало со значением заголовка).
- Используется в финальном `index.html`: `loadStatus()` делает `fetch(SUB_URL)`, парсит
  заголовок, рендерит прогресс-бар трафика и дату/дни до истечения (или «Без ограничения»,
  если `expire=0`/`total=0`).
- Если `fetch` падает (сеть/CORS/прочее) — страница показывает плашку с предупреждением, но
  сами конфиги и кнопки остаются рабочими (отказоустойчивость статус-блока).

## Deep-link схемы — подтверждено из исходного кода (`frontend/src/pages/sub/subPageModel.ts`)

```js
V2Box:     v2box://install-sub?url=<encodeURIComponent(subUrl)>&name=<encodeURIComponent(title)>
V2RayNG:   v2rayng://install-config?url=<encodeURIComponent(subUrl)>
Happ:      happ://add/<subUrl>                         // БЕЗ encodeURIComponent
```

OneXray и V2ray VPN Client: Xray Vless — deep-link схемы неизвестны/не подтверждены, для них
на странице — только ссылка на магазин + инструкция «скопировать ссылку подписки вручную».

**Не включены как заведомо несовместимые с REALITY на Xray ≥26.9.8:** Sing-box, Shadowrocket,
Streisand, Hiddify, Karing — явное предупреждение об этом есть в блоке «Приложения».

## QR-код — переключатель «Подписка» / «Сервер N»

- По умолчанию открыта вкладка **«Подписка»** (решение оператора 08.10.2026) — QR кодирует
  `subUrl` (с автообновлением конфигов при будущих изменениях на сервере).
- Доп. вкладки «Сервер» (по одной на каждый `{{ range .links }}`) — QR кодирует конкретный
  `vless://...` для разового импорта одного конфига (аналог поведения нативной страницы 3x-ui,
  где тоже есть выбор между QR подписки и QR конкретного сервера).
- Библиотека: `qrcode-generator` (kazuhikoarase), MIT, `js2.0.4`. Аудит 07.10.2026: нет сетевых
  вызовов, `eval`/`new Function`, скрытых base64-блоков — чистый алгоритм кодирования.
  `sha256sum`: `79ec86f82856005b1c887905cfccfcfbec3821ca61c7fd5a952faa5f778f791c`.
  Вендорится инлайн в собранный `index.html` (не подключается через CDN — страница отдаёт
  рабочие VPN-конфиги, зависимость от стороннего домена недопустима).
