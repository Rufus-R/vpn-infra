ниже все факты, проверенные на собственной инфраструктуре и в открытом

без дальнейших исследований.

## Механизм подключения кастомной темы

- Настройка: **Settings → Subscription → Information → Sub Theme Directory**
  (поле `subThemeDir` в `settings`).
- Файл обязателен: `index.html` (или `sub.html`) в указанной директории.
- Директория может быть в любом месте на сервере Panel, абсолютный путь.
- Контент-негошиэйшн по заголовку `Accept`: `text/html` → кастомный/встроенный
  HTML; без него (VPN-клиенты) → голый base64 конфигов (не затрагивается
  темой).

Panel использует стандартный Go `html/template`. Подтверждены рабочими все

| `{{ .subUrl }}` | ✅ | `https://netru.ru.net:2096/.../<subId>` |

| `{{ .totalByte }}` | ✅ | `0` |
| `{{ range .links }}...{{ end }}` | ✅ | реальная `vless://` ссылка на тестовый inbound |

**Важно:** `window.__SUB_PAGE_DATA__` (JSON, инжектируемый на встроенной SPA
странице) — это внутренний механизм React-бандла x-ui, **не связан** с
кастомной темой. В кастомном `index.html` он не появляется автоматически —
все данные доступны только через переменные `{{ .xxx }}` Go-шаблона выше.
Это уточнение отменяет часть предположений из более раннего внешнего
исследования.

## Deep-link схемы — ✅ из исходного кода (`frontend/src/pages/sub/subPageModel.ts`)

```js
// Android
V2Box:     v2box://install-sub?url=${encodeURIComponent(subUrl)}&name=${encodeURIComponent(sId)}
V2RayNG:   v2rayng://install-config?url=${encodeURIComponent(subUrl)}
Happ:      happ://add/${subUrl}                         // БЕЗ encodeURIComponent

// iOS (общие с Android, те же схемы)
V2Box:     (как выше)
Happ:      (как выше)
```

**Несовместимы с REALITY на Xray ≥26.9.8 (см. `system-state.md` п.5), НЕ включать в кастомную тему:**
`Sing-box` (`sing-box://import-remote-profile?...`), `Shadowrocket`
(`shadowrocket://add/sub://...`), `Streisand` (`streisand://import/...`).

**Нет deep-link схемы (не входят в нативный список 3x-ui — см. B9):**
OneXray, V2ray VPN Client: Xray Vless — для них на кастомной странице:
ссылка на магазин приложений + инструкция «скопировать subUrl и вставить
вручную».

## QR-код

Панель генерирует QR только для встроенной SPA-страницы (React-компонент
`QrCodeModal`, неотделим от фреймворка). Для кастомной темы — отдельная
лёгкая библиотека.

**Выбрана и проаудирована:** `qrcode-generator` (kazuhikoarase), MIT,
версия `js2.0.4`.
- Аудит 07.10.2026 (на S1): нет сетевых вызовов (`fetch`/`XMLHttpRequest`),
  нет `eval`/`new Function`, нет скрытых base64-блоков. Чистый алгоритм
  кодирования (Рид-Соломон), работает только с входной строкой.
- `sha256sum`: `79ec86f82856005b1c887905cfccfcfbec3821ca61c7fd5a952faa5f778f791c`
- Размещение: вендорить файл локально в директорию кастомной темы (НЕ
  подключать через внешний CDN — на странице, отдающей рабочие VPN-конфиги,
  зависимость от стороннего домена недопустима).
- Исходник сохранён на S1: `/root/qr-review/qrcode-generator-js2.0.4/js/dist/qrcode.js`.
