## Модель лимита устройств

SOFT-LIMIT: на тариф "N устройств" выдаётся N отдельных учётных данных
(N отдельных пользователей в Marzban под одной подпиской).
Технический enforcement одновременных подключений — НЕ в MVP.

## Триал

- Длительность: 7 дней
- Устройства: 1
- Условие получения: обязательна привязка номера телефона через Telegram
  (request_contact) — ТОЛЬКО в момент активации триала, не для обычной
  регистрации/просмотра тарифов
- Защита от повторного триала: проверка по tg_id И по номеру телефона
  (если номер уже использовал триал на другом tg_id — отказ)

## Реферальная программа

Бонус начисляется РЕФЕРЕРУ при первой подтверждённой оплате приглашённого
(не при регистрации — защита от абузы).

| Срок подписки реферала | Бонус рефереру |
|------------------------|----------------|
| 1 месяц | +7 дней |
| 3 месяца | +14 дней |
| 12 месяцев | +30 дней |

Бонус начисляется один раз (при первой оплате), повторные оплаты того же
реферала бонус не дают повторно.

## Оплата (MVP)

Способ: РУЧНОЕ ПОДТВЕРЖДЕНИЕ
1. Клиент видит реквизиты (самозанятость) в боте
2. Клиент переводит средства, нажимает "Я оплатил"
3. Уведомление админу в Telegram
4. Админ подтверждает кнопкой в боте
5. Бот активирует/продлевает подписку через Marzban API

Следующий этап (не блокирует MVP): ЮKassa для самозанятых
(автоприём + автоформирование чека в "Мой налог")
