# Быстрый старт новой сессии

Этот файл — точка входа для ассистента. Содержит только чеклист и ссылки.
Подробности о состоянии системы — в `system-state.md`.
Диагностические команды — в `diagnostic-commands.md`.

---

## 1. Ключевые файлы для чтения в начале сессии

Выполните на S1, чтобы получить полный контекст:

```bash
# Состояние системы: решённые проблемы, техдолг, открытые вопросы
cat /root/vpn-infra/docs/system-state.md

# Архитектура инфраструктуры
cat /root/vpn-infra/docs/architecture/overview.md

# Коммерческий проект: обзор
cat /root/vpn-infra/docs/commercial/overview.md

# Коммерческий проект: развёртывание (финальный рабочий конфиг)
cat /root/vpn-infra/docs/commercial/deployment.md

# Известные проблемы (коммерческий)
cat /root/vpn-infra/docs/commercial/known-issues.md
```

## 2. Диагностика (если нужно проверить состояние)

См. файл `diagnostic-commands.md` — там команды для каждого сервера
с ожидаемыми результатами.

## 3. Доступы

- Управление с Termux (мобильный) и Windows PC через PowerShell
- SSH-ключи настроены ко всем трём серверам (S1, S2, S_RU)
- Парольная аутентификация отключена на всех серверах
- S1 имеет ключ `~/.ssh/id_ed25519_servers` для управления S2 и S_RU

## 4. Монорепо

- GitHub: `github.com/Rufus-R/vpn-infra` (приватный, Deploy Key)
- Локально на S1: `/root/vpn-infra`
- Секреты зашифрованы через `git-crypt` (ключ сохранён в менеджере паролей)
