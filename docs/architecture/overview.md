## Логика трафика

1. **Все VPN-клиенты S1** → интернет через **S2**
   - policy routing: `from 10.9.0.0/24 lookup vpn`
   - таблица vpn: `default via 10.8.0.1 dev tun0`
   - NAT на S1: `MASQUERADE 10.9.0.0/24 → tun0`
   - NAT на S2: `MASQUERADE 10.8.0.0/24 → ens3`

2. **Family-клиенты** → дополнительно LAN `192.168.0.0/24` через OPNsense

3. **Friend-клиенты** → только интернет, без LAN

4. **OPNsense** → выход через VPN + NAT на самом OPNsense для LAN-клиентов

## DNS

Все VPN-клиенты получают push: `dhcp-option DNS 10.8.0.1`
Pi-hole на S2 слушает на `10.8.0.1:53` (только через tun0)
