## Действующие решения и ограничения

Только то, что влияет на текущие действия. Обоснования и история — в архиве (`archive/system-state-closed-2026-10-17.md`, «Решённые проблемы»).

- Домашний сегмент (S1/S2) — только OpenVPN; альтернативные протоколы не внедряются (26.09.2026).
- Проверка отключения парольного SSH — только через `sshd -T` (drop-in `50-cloud-init.conf` перебивает основной конфиг; плюс `ssh_pwauth: false` в `/etc/cloud/cloud.cfg`).
- Firewall S2 — только `ufw` (NAT в `/etc/ufw/before.rules`); Docker и `netfilter-persistent` удалены.
- Access-лог Xray отключается параметром `"access":"none"` в шаблоне; `loglevel:"none"` его не отключает.
- Geo-split на S_RU: теги `geosite:category-ru` и `geoip:ru` → direct, остальное через `to-s2-relay`; `geosite:ru` не существует.
- Подписки клиентам отдаёт только Panel (`netru.ru.net:2096`); на S_RU подписка отключена (29.09.2026).
- Клиенты: Hiddify, Shadowrocket и Karing не поддерживаются (несовместимость с Reality на Xray-core ≥26.9.8); рекомендован Happ (также V2Box, OneXray, V2ray VPN Client, v2rayNG).
- Тема подписки «Штиль» хранится только на Panel и в архиве старого Panel на S1; в git её нет.
