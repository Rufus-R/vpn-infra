## Открытые вопросы и технический долг

### Критические (блокируют работу)

1. **Мобильный клиент: тайм-аут через одного оператора**
   - Симптомы: работает только через одного мобильного оператора,
     через другого — timeout подключения
   - Возможные причины: DPI-блокировка, блокировка порта, IP-бан, MTU
   - План: диагностика на S2 (tcpdump, логи relay-node), проверка MTU
   - Варианты: смена порта на 443, обфускация, резервный протокол

### Важные (улучшение надёжности)

2. **Резервный канал S_RU ↔ S2**
   - Если VLESS+Reality (8443) заблокируют, нужен запасной туннель
   - Варианты: AmneziaWG в Docker, OpenVPN через UDP, Shadowsocks-2022

3. **Telegram-бот для коммерческого проекта**
   - Документация: `docs/commercial/bot.md`
   - Стек: Python + aiogram 3.x + SQLAlchemy 2.0 + asyncpg + Alembic
   - БД: Postgres в отдельном контейнере на S_RU
   - Интеграция с Marzban через HTTP API

4. **Скрипты автоматического развёртывания**
   - Цель: быстрое восстановление сервера из монорепо
   - Планируются: `scripts/deploy-s1.sh`, `deploy-s2.sh`, `deploy-sru.sh`

### Косметические (можно отложить)

5. **Git identity на S1**
   - Сейчас коммиты от `root@maximum.ru.net`
   - Нужно: `git config --global user.name "..."`, `user.email "..."`

6. **Бэкап домашней инфраструктуры**
   - Последний полный бэкап устарел
   - Нужно: актуальный дамп конфигов + PKI

7. **Настройка отзыва сертификатов (CRL) на S1**
   - Скрипт есть, но полный workflow отзыва клиента не протестирован
